# Check if a TidySet is fuzzy.

Check if there are fuzzy sets. A fuzzy set is a set where the
relationship between elements is given by a probability (or
uncertainty).

## Usage

``` r
is.fuzzy(object)

# S4 method for class 'TidySet'
is.fuzzy(object)
```

## Arguments

- object:

  Object to be coerced or tested.

## Value

A logical value.

## Methods (by class)

- `is.fuzzy(TidySet)`: Check if it is fuzzy
